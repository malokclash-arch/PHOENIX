# Phoenix — موقع phoenixiq.online

موقع Phoenix الرسمي: أنظمة المحاسبة والإدارة، موشن كرافك، التصميم الترويجي، الاستشارات، الكورسات، والدروبشوبنك.

## هيكل الملفات

```
index.html              الصفحة الرئيسية وكل صفحات الخدمات
assets/css/style.css    التصميم والألوان والحركات
assets/js/main.js       التفاعل، التنقل بين الصفحات، المعرض، روابط التواصل
assets/img/             الشعار، الأيقونة، وصور نماذج الأعمال
assets/video/           ريل «ماء بشعارك» (mp4 + webm)
CNAME                   الدومين phoenixiq.online لـ GitHub Pages
.nojekyll               حتى ينشر GitHub الملفات كما هي
```

## الرفع على GitHub Pages

1. أنشئ مستودع جديد على GitHub (أو افتح مستودع الموقع الحالي).
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على مجلد `assets` كما هو.
3. من **Settings ← Pages** اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`.
4. خلال دقائق يصير الموقع متاح.

### ربط الدومين phoenixiq.online

ملف `CNAME` موجود ومكتوب بيه الدومين. من لوحة الدومين أضف:

- أربع سجلات `A` للجذر تشير إلى: `185.199.108.153` و`185.199.109.153` و`185.199.110.153` و`185.199.111.153`
- سجل `CNAME` لـ `www` يشير إلى `اسم-حسابك.github.io`

ثم فعّل **Enforce HTTPS** من إعدادات Pages.

إذا ما تستعمل GitHub Pages لهذا الدومين، احذف ملف `CNAME`.

## تعديل روابط التواصل

بأعلى ملف `assets/js/main.js` تحت عنوان «عدّل روابط التواصل هنا»:

```js
const CONTACT = {
  telegram:  "https://t.me/PhoenixAid",
  whatsappNumber: "",               // مثال: "9647XXXXXXXXX"
  instagram: "https://instagram.com/",
  tiktok:    "https://tiktok.com/"
};
```

## صفحة أدوات AI

القائمة فيها رابط إلى `ai-tools.html`. إذا كانت هذه الصفحة موجودة بموقعكم الحالي، ارفعها بنفس المستودع بجانب `index.html` حتى يبقى الرابط شغال.

## روابط الصفحات

- الرئيسية: `/`
- أنظمة المحاسبة والإدارة: `/#/systems`
- موشن كرافك: `/#/motion`
- التصميم الترويجي: `/#/design`
- الاستشارات: `/#/consulting`
- الكورسات: `/#/courses`
- الدروبشوبنك: `/#/dropshipping`
